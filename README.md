# Travel with Pandu

**Travel with Pandu** is a production website for **Panduka Balasooriya**, a Licensed National Tourist Guide Lecturer in Sri Lanka.

The website presents Panduka’s personalised travel and concierge service, including guided tours, transport, airport transfers, hotel arrangements, and excursions. Visitors can submit trip enquiries directly through WhatsApp.

## Live website

The website is hosted on paid hosting and is intended for use with a custom domain.

```text
https://travelwithpandu.com/
```

## Purpose

The website helps potential visitors to Sri Lanka:

- Learn about Panduka’s licensed guiding and travel-planning service
- Understand the services offered
- See his qualifications and SLTDA licence details
- Submit a trip enquiry through WhatsApp
- Contact Panduka for a personalised itinerary

## WhatsApp enquiry system

The enquiry form creates a pre-filled WhatsApp message containing the visitor’s:

- Selected services
- Travel dates
- Group size
- Budget
- Additional requirements

When the visitor submits the form, WhatsApp opens with the message ready to send. This keeps the enquiry process simple and avoids the need for a separate backend or email server.

## Deployment

The production website is deployed through paid hosting.

To update the live website:

1. Make changes to `index.html`.
2. Test the updated file locally in a browser.
3. Commit and push the changes to GitHub.
4. Upload or deploy the updated `index.html` to the hosting provider.
5. Confirm that the live website and WhatsApp enquiry link are working.

## Before publishing changes

Check the following:

- WhatsApp number is correct
- Contact links work on mobile and desktop
- Guide photo and credentials are accurate
- Customer reviews are genuine
- Licence number is displayed correctly
- Website loads properly on mobile devices
- Custom domain and SSL certificate are active
